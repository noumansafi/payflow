# PayFlow client

Angular 20 wallet UI for the PayFlow API.

## Requirements

- Node.js **20.19+** or **22+**
- PayFlow API running on `http://localhost:8080` (see root README)

## Run

```bash
npm install
npm start
```

App: `http://localhost:4200`  
API proxy: `/api` → `http://localhost:8080`
